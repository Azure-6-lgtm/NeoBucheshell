# Installation

**NeoBucheshell** is very simple to install.
You have to build NeoBucheshell using cargo.
We do not provide prebuilt binaries for NeoBucheshell

## Installation steps
- Clone the repository
``` bash
git clone https://www.github.com/Azure-6-lgtm/NeoBucheshell
```
- Cd into the repository
``` bash
  cd NeoBucheshell
```
- From here, you can either build or run NeoBucheshell
- For building -
```
  cargo build # or cargo build --release
```
- For running -
```
  cargo run
```
- Note: You can copy the builded binary into a place in your PATH to make it work systemwide
