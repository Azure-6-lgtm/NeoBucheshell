# Getting started with NeoBucheshell

After installing NeoBucheshell onto your $PATH <br>
It is very easy to setup NeoBucheshell.

## Starting the shell

- To start the shell, simply type "neobucheshell" in your terminal
```neobucheshell```
- You can also supply arguments to the shell.
