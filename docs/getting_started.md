# Getting started with NeoBucheshell

After installing NeoBucheshell onto your **$PATH** <br>
It is very easy to setup NeoBucheshell.

## Starting the shell

- To start the shell, simply type "neobucheshell" in your terminal
``` 
neobucheshell
```
- You can also supply arguments to the shell.

## Launch arguments

NeoBucheshell has multiple arguments that can be passed on launch <br>
These include -

- **rc**: This runs a command and then starts the shell normally.
```
neobucheshell -rc {your command}
```
- **ver**: This prints the version of neobucheshell you are using and exits
```
neobucheshell -ver
```
- **help**: This prints the help screen the same as the help command would do and exits
```
neobucheshell -help
```
For more knowledge,next see[Commands](commands.md)
