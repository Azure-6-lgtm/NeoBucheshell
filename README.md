# NeoBucheshell

A remaster of my old shell Bucheshell
It aims to be faster,more optimized and friendlier
NeoBucheshell will be part of my upcoming coreutils alternative

## Features
- Custom prompt
- Command execution
- Built-in commands
- Aliases
- Pipes
- Redirection
- Configuration
- Logging system
